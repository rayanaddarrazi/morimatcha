# Waar pas ik wat aan?

| Wat | Waar |
|---|---|
| Home, Shop, Abonnement, Bereiden | Pagina's > pagina openen > **Pagebuilder** (blokken toevoegen, verslepen, verwijderen). Onderaan elk blok: tab **Opmaak** (kleur, ruimte, anker) |
| Producten, prijzen, maten, foto's | WooCommerce > Producten. Extra velden en blokken onder de aankoop staan op de productpagina in de editor |
| Menu en footerlinks | Weergave > Menu's (hoofdmenu, footer shop, hulp, Mori) |
| Logo's, mededelingsbalk, footertekst, betaalmethodes | Instellingen Mori > Algemeen, Mededeling, Footer |
| Winkelwagenpaneel | Instellingen Mori > Winkelwagen |
| Teksten bij de aankoop, korting abonnement | Instellingen Mori > Producten en Aankoop |
| Afrekenen, bevestiging | Instellingen Mori > Afrekenen, Bevestiging |
| Mijn account en het venster Opzeggen | Instellingen Mori > Mijn account |
| 3D-blik aan of uit, labels | Instellingen Mori > Blik in 3D |
| Beschrijving voor Google | Instellingen Mori > Zoekmachines (standaard), of per pagina of product rechts in de editor |
| Abonnementen van klanten | WooCommerce > Abonnementen |
| Verzending, betaalmethodes | WooCommerce > Instellingen > Verzending en Betalingen |
| Nieuwsbriefaanmeldingen | Dashboard > Nieuwsbrief |
